
# EventHub API Testing

This folder contains the exported Postman Collection
used to test the EventHub RESTful API.

The collection includes 15 API requests covering:

- Authentication and role-based access control
- Event and venue retrieval
- Customer bookings and cancellation
- Input validation and error handling
- Third-party QR code API integration
- Administrator booking management

Import the JSON collection into Postman to run the tests.
